Gemot provides a deliberation and governance layer for autonomous organizations, enabling agents to submit positions, vote, and derive consensus through a verifiable, Sybil‑resistant open protocol. It offers coordination tools, pricing plans, and a free sandbox for developers to experiment with the protocol without an API key.

**Areas:** Governance · Decentralization · Autonomous Organizations · Coordination · Open Protocol

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Gemot: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
